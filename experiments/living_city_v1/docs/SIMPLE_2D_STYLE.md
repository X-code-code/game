## 画面语言

- 可爱治愈的 2D 手绘卡通，cozy casual mobile game，柔和低饱和色、清晰细棕线、轻微手绘质感，绘本与贴纸气质。
- 统一正面略带俯视的平行视角，建筑保持一致透视；不使用写实 3D、强消失点或几何拼接造型。完整立面 PNG、透明道具、角色和前景共同组成街区。
- 从道路、建筑、居民到台面小物逐级阅读；不同屋顶和服装保留色相区别，绿地与石路分区明确。寻物摆在有用途的承托面上，并提供可读线索。
- 用户桌面 `bg-png` 四张截图是构图与绘画语言参考，不是运行素材批准，不把截图像素直接放入游戏。新素材只使用重新生成的原创图。

## 资产与角色

所有建筑、店铺、摊位、树、家具、装饰、道具、鸡和 UI 均由内置 image_gen 制作。单个物件尽量单独生成透明 PNG；连续地面可为不透明 PNG。先替换建筑，再处理鸡和其余视觉资源。禁止代码制作或重画游戏美术。

每只鸡固定一套设计，动作从对应生成精灵图机械裁切。当前 v4 八名居民共 132 张独立帧，注册画布 384×256、脚点自左上 `(192,215)`、可见角色高 186 像素。第一关先将居民世界高度调整到约 78–90，职业美术与新动作随后更换。走路帧体现交替脚步；待机、递杯、喝茶、持物和招呼使用生成姿态。程序仅播放帧、镜像或调度动作，不绘制身体与服饰。

源图、实际提示词、原图 SHA、裁切/缩放/透明扩边参数和运行映射保存到 `art/production/ai_image_v4/`，最终 PNG 存入 `assets/generated/`。保留源图原始字节；机械处理不描线、不补画、不改变物件造型。运行时设置位置、锚点、缩放、层级、动画、点击区和状态。

v7 新增八名居民各有独立 3×2 精灵表，共 48 个最终 cels。每只鸡六帧使用共同 sheetScale，注册到同一 384×256 画布和 `(192,215)` 脚点；schema2 仅包含真实待机、左右侧向行走和岗位动作，新增路线限定同 y 的横向往返。原始表与 walkfix 选用表均保留真实来源，使用帧由 PNG 机械裁切得到，原 v4 schema1 方向清单继续保留。

## 游戏内验收

v12 清晰度与动作规范：场景的世界尺寸和图片像素尺寸分开登记，按源图真实分辨率导出 2–3 倍纹理，由 `textureScale` 加载，禁止只把低清运行 PNG 放大。必须在最大缩放下对比小物及其承托背景，不能只看目标自身。第一关 64 个现有槽已重导出，基础大地面暂保留原分辨率。16 居民改用 v12 的 220 帧，四张真实待机表情配不等时眨眼、各自错开相位，短停不得反复重置同一表情。实际支持的行走方向每四帧循环，0.1 秒/帧；这不代表游戏渲染帧率。详见 [迭代 15](LIVING_CITY_ITERATION_15.md)。
