# 活街区：简化 2D 绘制规范 v1

**状态：2026-09-28 用户选择的新方向；独立工程试产。** 本规范只替代 `living_city_v1` 的水彩试验，不改变当前可玩版。旧水彩参考与生成图保留为历史记录，不进入本风格的运行资源。

## 画面语言

- 一张连续的近俯视、近似平行投影街区。建筑看得到浅屋顶和短立面，摊位看得到台面与正面；道路不使用消失点。角色脚点、柜台面、树根和阴影都按 `design/street_block_01.json` 的世界坐标摆放。
- 用**原创 2D 绘制形状**组成角色和场景：清楚的大轮廓、少量不规则手绘线、2–3 层平缓色块和极轻的局部颗粒。线是暖深棕 `#634A3B`，约 3 世界单位的场景外轮廓；256 px 角色源图外线约 4–5 px，缩到普通视图仍有约 1 px。内部线更细且断续。不要照片、水彩模型纹理、塑料渐变或均匀的机械圆角图标。
- 主色：奶油路面 `#E9DFC7`、暖白羽毛 `#F3E6C6`、麦黄 `#D9AB62`、赤陶 `#B9684D`、栗木 `#88654A`、鼠尾草绿 `#8FA789`、灰蓝 `#6F8B95`。同一组颜色用于建筑布幌、服装和 UI，暗部用暖灰棕，光从左上来。用局部色相与明度区分摊位，不用霓虹描边突出任务物。
- 细节密度分三级：先读出道路、四个店区和活动鸡；放大一级读出柜台/货架/树冠与行走路线；再放大读出杯、顶针、布结和夹子。每组小物有承托面及使用者，不在空地均匀撒图标。

## 鸡的造型和动作

- 年轻信使鸡为第一只源角色：头高约全身 28–32%，蛋形胸腹、短喙、短尾、两条清楚的鸟腿与三趾，翅膀仍是羽翼而非人手。灰蓝短背心与赤陶小挎包分别保持同一侧的结构。普通视图先按 79 px 身高审，另在 56 px 宽镜头备选和 127 px 放大下审。
- 走路是**不同承重姿势的逐帧动画**：右脚着地、身体越过、左脚着地、再越过；头/胸/翅膀/尾巴随重心联动。向北、西北、东北各画对应方向，不能用侧面帧横向滑动，也不能把西北帧简单镜像成东北帧。待机有呼吸/眨眼；递杯有停、看、伸翼、接、回稳的因果。
- 每帧共用 `256×256` 透明画布和同一脚点 `(128,215)`（自左上），可见角色高约 180 源像素。按场景世界高 120 放置。衣物、喙、鸡冠数量、包扣位置在各帧保持连续；地面接触影是独立场景层，不烘焙进角色 PNG。

## 生产文件与游戏文件

- 源文件优先用可编辑 SVG 或分层 OpenRaster；生成脚本与参数同资源 ID 保存。每个动作帧、建筑层、前景层从源文件**确定性导出** PNG；精确画布、Alpha 和命名由脚本/验收检查，不依赖模型猜测。
- 场景按蓝图 `artSlots` 绘制：地面不透明；店面背景、柜台前缘、树冠、路边货物、横幅等各自透明。按脚点排序与固定上层组合。任务物独立透明图和点击区，视觉自然融入摊位。
- 每次先看 `444×960` 初始视图、茶摊局部和最大缩放；其次看 10 秒无操作回放、遮挡、拖动误触、任务点击。**没有入游戏小样与源文件的资源不标为获批。**

## 立即验收的第一块内容

先画茶摊周围的地面、后架、柜台前缘、布幌和信使鸡；导入独立工程检查完整的走来、停步、递杯、离开。这个小样通过后复用语言绘制其余店面与鸡，避免先量产再发现同屏比例不合。
