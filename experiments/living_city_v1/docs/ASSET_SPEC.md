# 游戏美术资源规格（试产草案）

**状态：试产草案。** 源图尺寸是向 ChatGPT Web 推荐的生成画布，最终游戏尺寸由 Codex 对收到的源图后处理并实测。精确像素、PNG/WebP/JPG 编码及 Alpha 不能仅凭生成模型的描述认定达标。

| 资源类型 | Generation Spec | Final Game Asset Spec | 透明背景 |
| --- | --- | --- | --- |
| 鸡母版参考 | 当前修订批推荐 1536×1536，1:1，单只完整幼鸡，占画布高度约 70–76%，四周 ≥12% 安全边距 | 审核通过后统一为 `art/reference/chicken_master_reference.png`，1024×1024 PNG；参考图不作为游戏精灵导入，`targetGameSize: null` | 否：浅暖米白，可有极轻且均匀的纸纹，无背景物。 |
| 可动画鸡的独立层 | 每层推荐 1024×1024 透明源画布，动作允许更窄构图但不裁切 | 暂定各层 256×256 或按锚点设计统一画布，需首次入游戏小样后定稿 | 是，完整真 Alpha。 |
| 独立隐藏物 | 推荐 1024×1024，1:1，单件居中，四周 ≥12% 安全边距 | 暂定 256×256 PNG/WebP，触控判定另由 CityConfig 的 clickArea 定义 | 是，干净 Alpha；无烘焙地面阴影。 |
| 城市背景小样 | 推荐 1536×1024 左右，3:2，仅静态背景层 | 按地图比例及纹理预算裁切/缩放，首批小样目标尺寸待游戏实测；不能预先声称直接适配 2400×1600 地图 | 否。 |
| 前景遮挡物 | 推荐 1024×1024，按具体对象补足安全边距 | 目标尺寸随对象实例与地图比例确定；独立层和渲染顺序需先在游戏验证 | 是。 |

## 命名与目录

英文小写 `snake_case`，全局唯一 Asset ID；文件名原则上为 `<asset_id>.png`（若获批最终编码为 WebP/JPG，则更新清单而不改 Asset ID）。参考图在 `art/reference/`，Web 源图和候选稿在 `art/generated/<batch_id>/`，审核记录在 `art/review/<batch_id>/`，获批且可导入的成品再写入城市或公共 Bundle。`art/asset_manifest.json` 记录真实状态，不以请求清单代替已交付文件。

同一资源的修订批次沿用稳定 Asset ID，并在批次清单用 `revisionOf` 指向前一批；全局清单中的候选源图可用单独的候选 ID 保存审核结论。用户选择的 `art/reference/chicken_cast_style_guide_v1.png` 是**画风方向参考**，不等于鸡母版获批，亦不作为运行时资产。

## 后处理验收

Codex 收到用户从 Web 下载/上传的源图后：核对一图一资源及命名映射；检查图像实际尺寸、色彩空间、透视与边缘；透明资源检查真实 Alpha（不接受棋盘格或纯白底伪透明）；按构图保留安全边距；必要时抠图、裁切、统一画布、缩放；转为明确的 PNG/WebP/JPG，压缩并确认文件字节与游戏显示尺寸。缩图前后做 contact sheet，人工判断能否在手机内辨认。缺少源图时不能执行或报告这些步骤已完成。

不把占位绘制中的 `demo_*` 字符串直接当作文件名。正式资源进入游戏前必须完成 Asset ID 到 Bundle 路径与 SpriteFrame 的映射，以及背景/前景/分层角色的渲染接入。
