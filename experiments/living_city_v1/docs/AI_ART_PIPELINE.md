# AI 生图与 PNG 加载流程（2026-10-01）

本文件与根目录 `IMPORTANT.md` 是当前有效制作规则。历史的代码绘图、原生矢量绘制、SVG 角色源和“生图仅作概念参考”流程已废止。用户授权直接调用内置 image_gen 制作运行资产并接入验证，不等待 Web 交接或额外审批。

建筑、摊位、植物、家具、装饰物、寻物道具、交互状态和鸡角色都使用内置图像生成。禁止 Pillow ImageDraw、SVG path、Canvas、Cocos Graphics 等程序绘图制作或补画这些资产。运行代码只加载 PNG、设置坐标/锚点/缩放/层级、播放动画、处理碰撞、点击和游戏状态。

风格：可爱治愈的 cozy casual mobile game，柔和低饱和色、干净细棕线稿、轻微手绘质感、绘本/贴纸气质。统一正面略带俯视的 2D 平行视角，不采用写实 3D 或强烈对角等距视角。现有截图作为参考，生成新的原创物件。

每个源资产记录真实提示词与生成来源。`art/production/<batch_id>/sources/` 保存工具原始 PNG，`prompts/` 保存实际提示词，`production_manifest.json` 保存生成尺寸、Alpha、SHA、处理参数、最终尺寸和 Bundle 映射。`generation_record.json` 记录工具原始输出路径及其 SHA。v4 的 86 张使用源图保留；v5 分步大修单独建批次，第一关场景与其余仍在使用的 v4 角色、目标、UI 和两关场景分别登记。不得将风格参考或运行检查通过记作玩家视觉批准。

同一生成源可机械导出多份图片用于新区域，但须记录真实共用源与提示词，不能声称重复导出是一次新的生图。被替换的源图、最终 PNG 和导出参数保留为历史记录；历史 runtime 路径不再表示当前加载的内容。

第一关内容扩充批 `ai_image_v6` 沿用 v5 画风。12 个有效新源由 13 次生成/编辑得到：6 个场景物件、3 张四格目标图、3 张双帧容器图；原带篮子的野餐垫是未用候选，编辑后的空垫子与独立开合篮子一起使用。另有 30 个场景实例复用 7 个 v5 生成源，原图、真实提示词和来源链复制保留。两帧容器采用共同缩放比例与统一脚点，避免打开时底座跳动。最终新增 54 个 PNG（36 场景、12 目标、6 状态），原场景/目标/角色文件保留。`art/asset_manifest.json` 按关卡记录 v4/v5/v6 的实际运行范围。

上一轮 v7 街坊布局保留上述批次历史，退下 18 个无目标重复家具实例，再接入 6 个独立生图立面与 8 名独立生图居民；实际配置为 49 场景槽、11 建筑、16 居民、24 目标和 6 机关。`ai_image_v7` 新增 54 PNG：6 建筑及 48 cels。八张选用的 3×2 精灵表各按整表共同 sheetScale 机械裁切六帧，统一画布 384×256、脚点 `(192,215)`；schema2 只登记生成的待机、侧向 walk 与岗位 job，对应运行 clip 为 `idle_w`、`walk_nw`、`receive_w`。新增路线只做横向往返，缺失方向保留真实待机姿态。

v7 源图、真实提示词、原始候选、实际选用 walkfix 版本、生成输出路径及 SHA、裁切/缩放/注册参数和 Bundle 映射保存于 `art/production/ai_image_v7/`。候选不覆盖或冒充选用版本，不把机械复用登记成新生图。第一关实际混用 v5/v6/v7 场景、v4/v6 目标和机关、v4/v7 角色以及 v4 UI，后两关仍保留过渡资源；已有目标、机关与存档 ID 保留。最终 PNG 放置记录见 `art/review/ai_image_v7/placement_review.json`；本轮 Web Mobile 完整三关基线及最终第一关复测通过，见 [迭代 10](LIVING_CITY_ITERATION_10.md)，视觉批准 pending，微信真机未测。

最终 PNG 位于 `assets/generated/`，以清晰的 snake_case 命名；相同字节导入现有城市 Bundle，以保留城市 ID、关卡配置、已有资源 UUID 和存档路径。`assets/generated` 自身作为独立资源 Bundle，避免原始/最终资产直接混入首屏主包。

后处理只进行机械操作：从生图精灵图按实际对象间隔裁切，等比缩放，扩展透明画布，注册脚点，清除极低 Alpha 的透明杂点，检查文件格式与尺寸。v8 七块纯平面铺地按实际 Alpha 包围盒重采样到配置足迹，只缩放已生成的石砖像素；人物、景物和寻物仍等比缩放。由 Sharp 处理已有像素，不含任何绘图 API、轮廓描线、几何补画或角色变形。原始生成图不修改。

鸡角色使用固定生成母版参考；每只居民使用同一张生成精灵图内的连续动作。最终画布 384×256，脚点 `(192,215)`，角色身高参考 186 像素；加宽透明画布保留伸翅和工具动作，身体不变形。走路包含交替脚步，背面不画正面五官，角色事件使用生成的递杯、喝茶、拿物或招呼姿态。程序只播放图片帧与镜像。

验收先检查真实 Alpha、尺寸、锚点与源图可追溯性，再在实际 Cocos Web Mobile 中检查手机画幅、最大缩放、全部角色加载与活动、拾取/翻找/提示、完成反馈与存档恢复。微信真机和玩家视觉批准状态另行如实记录。

当前运行目录只开放茶摊街区、花园集市、河畔码头三关。旧试验城市的配置和素材保留为历史记录；其存档自动回到当前第一关，同时保留旧城市的进度数据。每个当前城市先加载实际引用的蓝图、动作清单和 PNG，再挂载页面，避免快速切关时卸载尚有下载请求的资源包。

v8 庭院/小物/茶摊批共16次内置生图、15采用源及一张未用茶客候选，导出14场景、12目标和14角色帧共40PNG。三张四物图集裁为独立目标；茶摊主2×2、茶客5×2表按实际源图尺寸的四舍五入格界裁切，共同比例与脚点注册。茶客初版同脚候选、实际walkfix编辑、全部真实提示词/输入参考/原始字节/SHA保存在art/production/ai_image_v8/；源图检查与运行状态见[迭代11](LIVING_CITY_ITERATION_11.md)。角色schema2只登记实际拥有的方向与动作，主动邀请和自动茶客交接只播放生成PNG。
