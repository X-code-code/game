# 迭代 18：店铺、庭院与道路的摆放关系

2026-10-04，用户明确指出不合理之处在“建筑、道路和家具的位置关系”。本轮改第一关现有实例的位置，不扩充内容、不改变居民路线。

## 问题与处理

原画面将两个相同洗手台、花架、餐桌和果蔬架散放在道路两侧，缺少与店铺用途的联系；蓝色店铺独立落在草地上，挂旗横跨道路却没有支点。局部庭院整理没有解决这些整体关系。

调整八个现有实例：

| 现有实例 | 调整后的用途与位置 |
| --- | --- |
| 蓝色店铺 | 移至糖果店左侧，入口接入现有共享铺地 |
| 草地上的茶桌 | 移入蓝色店铺前的铺地区域 |
| 糖果庭院灌木 | 从新店铺门前移至庭院侧边 |
| 路口东侧洗手台 | 移到花店侧边，靠近花架的使用区 |
| 路口西侧洗手台 | 移到园艺小屋右侧庭院 |
| 路边果蔬架 | 移到面包店右前侧，避开门口 |
| 路边种子花架 | 移回花店庭院西侧 |
| 悬空挂旗 | 等比缩至原宽的 75%，挂到茶店雨棚立面 |

种子袋、苹果、小水壶及关联容器随承托物同步平移，碰撞底座与排序脚点同步更新；三条线索改为实际的新位置。现有图片原始字节、UUID、32 个目标 ID、8 个机关、16 位居民路线及事件、存档格式不变。场景仍有 65 个槽、11 栋建筑。
