==================================================
一、项目产品定义
==================================================

这是一款：

“鸡仔旅行主题的大场景探索寻物微信小游戏”。

核心视觉主角是：

鸡。

玩家跟随一群鸡前往不同城市。

每座城市都是一个大型、细节丰富的 2D 场景。

玩家可以：

- 拖动画面
- 缩放画面
- 浏览城市
- 寻找隐藏物品
- 寻找特定鸡角色
- 观察鸡的行为
- 点击鸡
- 发现隐藏互动
- 完成城市探索任务
- 收集城市纪念品
- 完成当前城市主要探索后前往下一座城市

产品体验重点不是传统“闯关”。

不要把游戏设计成：

第1关
第2关
第3关
下一关

统一使用：

城市
探索
目的地
下一站
城市探索完成
前往下一座城市

例如：

杭州探索完成

下一站：
上海

按钮：

继续探索

前往上海



==================================================
二、核心体验
==================================================

游戏最重要的体验是：

“一个充满会动小鸡的大场景”。

玩家打开城市以后不能感觉自己在看一张死图。

场景应该不断有轻微动态：

鸡走路
鸡啄东西
鸡睡觉
鸡眨眼
鸡从箱子后探头
鸡抱着东西走
鸡偶尔停下来
某些装饰轻微运动

但游戏本质仍然是轻量休闲寻物。

不要发展成：

复杂 RPG
模拟经营
战斗游戏
复杂 AI 模拟器

鸡的行为目的主要是：

增加生命感
增加观察乐趣
增加寻物难度
产生幽默场景
成为任务目标



==================================================
三、目标平台和技术栈
==================================================

目标平台：

微信小游戏

不是普通微信小程序页面。

游戏引擎：

Cocos Creator 3.8.x

主要语言：

TypeScript

要求最终可以：

Cocos Creator
→ 构建微信小游戏
→ 微信开发者工具
→ 真机运行

所有平台相关能力必须隔离。

不要让游戏业务代码到处直接调用：

wx.xxx

设计统一：

PlatformAdapter

例如：

PlatformAdapter.saveLocal()
PlatformAdapter.loadLocal()
PlatformAdapter.vibrateShort()
PlatformAdapter.share()
PlatformAdapter.showRewardedVideo()
PlatformAdapter.getSystemInfo()

Editor / Web 环境需要提供 fallback。

业务系统不知道自己运行在微信还是浏览器。
