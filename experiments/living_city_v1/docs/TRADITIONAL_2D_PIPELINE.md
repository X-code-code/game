# 活街区传统 2D 制作顺序

> **2026-10-01 当前规则：** 游戏美术全部使用内置图像生成制作，最终 PNG 保存到主线 `assets/generated/`；禁止代码绘图重画建筑、角色和场景物。当前规格与验收见 [AI 生图流程](AI_ART_PIPELINE.md)。本文较早风格、分层绘制和 Web 等待流程仅为历史记录，不覆盖最新用户授权。

**目标：** 在独立工程中做一块真正能走、能遮挡、能寻找、有人物生活动作的水彩鸡街区。当前可玩版保持原样；灰盒与失败候选都不作为正式美术。

## 1. 关卡灰盒（已在独立 Cocos 工程运行）

`design/street_block_01.json` 记录 1536×2048 地图、近俯视平行投影、相机、23 个美术位置、四块连通公共可走区、五只鸡的计划、茶摊柜台两侧脚点与递杯点、前景遮挡、四个寻物归属位置。`node tools/validate_street_block.mjs` 已通过几何及初始目标的 HUD 安全距离检查。独立工程的 Cocos Web Mobile 构建和 `444×960` 浏览器操作验证已通过，见 `docs/GREYBOX_RUNTIME_REPORT.md`。灰盒仍是几何图，没有正式画面。

## 2. 角色母版与动作源文件

先画一只与 `art/reference/chicken_cast_style_guide_v1.png` 同视觉语言、但设计原创的信使鸡；在普通视图约 79 px 身高下审轮廓、头身比和服装辨识度。交付可编辑分层源文件，至少保留 `body`、`head_neck`、`wing_far`、`wing_near`、`leg_far`、`leg_near`、`eye_open`、`eye_closed`、`bag`、`scarf`；每层补足关节背后被遮住的像素，所有层共用画布、角色比例和脚点。另画角色转向与走路关键姿态，不靠整张图来回滑动。

首个动作包：待机/眨眼、左右脚交替的走路循环、停步转头、伸翼接杯。先做实际尺寸的连续回放，再添加服装变体和其他鸡。摊主需要对应的取杯/递杯动作；杯子是独立道具，移交时有唯一的世界坐标。水彩纹理与暖棕线条在各帧保持一致。

## 3. 场景绘制与导出

依据灰盒在同一视角绘制地面、四个店面、茶摊后层、柜台前层、遮阳棚、栗子车、树、花盆、长凳、货物、灯柱和横幅。每个 `artSlot.id` 对应一份可编辑源层和一张导出图；透明前景的 Alpha 干净。地面不含角色、可移动道具或需要遮挡的摊位前沿。全场从左上受同一柔光，线宽、颜料颗粒和色域以已选风格参考校准。

每件隐藏物先定义所属摊位和承托面，单独绘制与点击；放大后可辨，普通视图不凭高饱和描边直接跳出。角色与场景按同一屏幕尺寸并排审图，避免“角色贴在一张画上”的边缘、光照和尺度差异。

## 4. Cocos 装配与验收

把关卡 JSON、场景层和角色动作导入独立城市 Bundle。角色按脚点排序，柜台、树、车等前景按明确遮挡边界合成。事件按“走来 → 脚落稳 → 双方转头 → 递杯 → 离开”播放；其他鸡各有独立节奏。任务物与线索、可见区域、触控区域一致。

验收只看**本工程**的 Web Mobile 与微信真机输出：444×960 初始视图、常用和最大缩放、十秒无操作回放、茶摊事件、寻找四件目标、拖动缩放误触、帧率/内存/包体。小鸡不滑步、不穿过柜台、动作细节不跳变，三种活动在首屏可读后，才能把此街区作为正式生产模板。
