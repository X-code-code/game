# 活街区独立工程约定

本工程按传统 2D 游戏流程制作。仓库根目录原工程的 `assets/`、`settings/` 和 `build/` 是原有功能基线，不在本工程的制作过程中修改。

当前试产方向按用户 2026-09-28 的选择改为**简化、可程序绘制的 2D**，有效画面规范见 `docs/SIMPLE_2D_STYLE.md`。旧水彩风格规范、生成图和四视图模板保留为历史试验，不能当成此版本的获批素材。原创可编辑绘制代码、SVG 等可作为角色与场景源文件；导出游戏 PNG 后仍要检查逐帧动作、分层和手机实际画幅。

1. 先以 `design/street_block_01.json` 的关卡灰盒检查镜头、可走区、阻挡、站位、交互和遮挡，再绘制正式素材。灰盒不是可交付美术。
2. 场景由共享投影和光照的地面、建筑、摊位、前景遮挡、角色、效果层组成。所有动态物都需要独立可编辑的源层和锚点；不把角色或互动区烘焙进一张背景图后补贴图。
3. 重点小鸡先设计固定造型与比例，再用同一套可编辑绘制源逐帧输出不同动作。行走必须有交替脚步与接地姿态，事件必须有对方、道具和场景站位相互对应。整张立绘平移、摇摆或独立生成两张姿态不能充当角色动画。
4. 图像生成只可作为构思参考。任何生成图要保留源图与真实提示词、记录缩图/Alpha/一致性验收，不能跳过手工补画与动画审查成为正式运行素材。`art/generated/chicken_rig_001/` 的两个候选未获准作为角色母版或 rig。
5. 正式素材进入 Cocos 前保留可编辑的分层源文件、统一坐标和导出清单。运行验收需覆盖普通手机尺寸的十秒无操作回放、角色脚点、前后遮挡、目标可发现性、拖动缩放和真机帧率。

具体制作顺序与交付件见 `docs/TRADITIONAL_2D_PIPELINE.md`。
