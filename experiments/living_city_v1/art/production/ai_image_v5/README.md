# v5 第一阶段：宽街区与场景构图

本批次使用内置 image_gen 原始输出，运行代码只加载 PNG、定位、设置深度和播放已有图片帧。地图为 2304×2048，四座主体店铺和南侧邮局缩至上一版宽高的 80%；两侧新增休憩和茶桌区域。

当前 25 个场景 PNG 导出由 14 张独立新生图、5 张 v4 源图原样复用以及 6 份当前新源的重复导出组成。重复家具不是新的生图调用。地面是完整不透明 PNG，其余对象有真实 Alpha。源尺寸与最终尺寸分别记录，原始图片不改；Sharp 仅作裁切、等比缩放、透明画布注册和低 Alpha 清理，没有绘图或补画。

- `sources/`：工具原始输出的字节拷贝，包括未采用候选和已替换的窄地面。
- `prompts/`：实际调用提示词。茶店当前源的真实提示词是 `shop_tea_v5_edit.md`。
- `generation_record.json`：实际工具输出路径、SHA、引用图片参数/哈希、历史来源与验收状态。
- `import_plan.json`：25 个槽位的尺寸、脚点、透明要求与运行注册计划。
- `production_manifest.json`：来源、机械处理参数、最终 PNG/UUID 和运行证据；窄地面保存在 `historicalExports`，其旧 runtime 路径已被宽地面接替。

五个历史复用源为针线盘、布料架、邮舍、布幌和蒸汽，其实际 v4 提示词与工具输出来源保留。角色、目标、翻找状态、UI 及第二三关仍是 v4 资源，本阶段不记作全美术大修完成。

三关基线：`art/review/ai_image_v5/three_chapters/runtime_report.json`，36 次拾取、9 次翻找与存档/旅行通过。摊主坐标最后修正后的专项：`art/review/ai_image_v5/chapter_1_vendor_adjustment/runtime_report.json`，12 次拾取、3 次翻找、左右真实拖动与40秒内两次递茶通过；该报告引用基线 SHA。两份运行报告均零错误、警告和失败请求。玩家视觉批准仍待反馈，微信真机未运行。

剩余问题明确保留：两侧区域内容密度不足；旧鸡的画风与动作仍须统一，旧目标 PNG 的色彩也偏淡。下一阶段生成这些资源并增加目标与藏法。
