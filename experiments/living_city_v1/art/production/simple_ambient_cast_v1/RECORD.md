# 街区居民程序绘制试产记录

**状态：trial_unapproved。** 这是独立 `living_city_v1` 工程里的程序绘制角色，不是已获批美术，也没有预制 PNG。`assets/scripts/character/AmbientChickenPainter.ts` 是唯一绘制源，`assets/scripts/map/LivingCityGreybox.ts` 按蓝图 role 调用。颜色与线宽遵循 `docs/SIMPLE_2D_STYLE.md`；脚点在角色节点 `(0,0)`，基准身高 120 世界单位，按各 NPC 的 `actorHeight` 等比缩放。

| Asset ID / role | 可读造型 | 行走及停步动作 |
| --- | --- | --- |
| `vendor` | 蜜黄色羽毛、灰蓝头巾、赤陶围裙、手持茶杯。 | 茶摊内整理杯具；信使到达时抬翼递杯，事件后回到工作循环。 |
| `ambient_shopper` | 奶油白羽毛、鼠尾草绿上衣与斜背小包。 | 沿街横穿，双脚交替、挎包随身体摆动；停步呼吸和眨眼。 |
| `ambient_vendor` | 深麦色羽毛、赤陶色帽、绿色围裙和木勺。 | 栗子摊位前往返照料货物，木勺有独立扫动。 |
| `ambient_watcher` | 奶油白羽毛、灰蓝披肩，站在街边。 | 呼吸、眨眼，按独立时间周期抬翼招呼。 |
| `tea_regular` | 蜜黄色羽毛、短灰蓝背心、栗色软帽和小杯；帽檐改变头部轮廓。 | 路线上左右脚交替、胸腹起伏与尾羽摆动；停步后举杯到喙前、低头啜饮、放回腰间，偶尔眨眼。 |
| `flower_buyer` | 奶油白羽毛、赤陶色宽下摆外套、绿色包头巾、编织提篮与独立小花。 | 行走时两脚交替，提篮相对身体摆动；停步时抬翼、略低头观察篮中的花，花茎与篮筐仍保有连接关系。 |
| `lane_child` | 计划身高 103 世界单位，露出高羽冠、赤陶色长围巾，造型比居民轻小。 | 更短促的步频、较大的交替抬脚与身体弹跳；停步时伸翼招呼，围巾尾端跟着步态摆动。 |

七位程序绘制配角共用喙、翼羽、尾羽、脚趾与暖棕描线几何；服装、携物轮廓和动作周期分别编排。胸部、头部、翼、脚、携物在每帧重绘，未使用整张贴图平移。地面接触影由运行时代码独立画在角色脚后，不烘进源图。隐藏物不附着在这些 NPC 上。本批直接以可编辑 TypeScript 路径指令生成运行画面，没有 AI 源图、PNG 后处理或图像生成提示词；上表每个角色的造型、动作规格就是相应 Asset ID 的制图任务记录。

## 2026-09-29 三向朝向补绘

- 对这七个 Asset ID 增加正面（向南）、背面（向北）程序绘制姿态。原有左右侧面姿态和岗位动作保留；信使仍使用自己的逐帧 cel，不走本绘制器。
- 背面不画眼睛和喙，重画后脑羽毛、衣服背缝与翅膀；正面有双眼、居中短喙和胸腹。三向都共享 `(0,0)` 脚点、交替抬脚及独立身体起伏。不是将侧面轮廓旋转或镜像充当纵向走路。
- 每个方向保留角色标识：茶摊主的赤陶围裙与灰蓝头巾、购物者的绿衣与斜挎包、栗子摊主的绿围裙与木勺、看灯者的灰蓝披肩、茶客的灰蓝背心与杯、买花者的红外套与花篮、孩子的长围巾。正背面道具仍画在角色周围，但手机默认倍率下可读性须由运行画面再审。
- 路线朝向按当前目标的位移向量更新：`|dy| > |dx|` 时选朝北或朝南，否则保持左右侧面；停步时不覆盖最后朝向。首帧也从第一段路线推断，避免开始的一帧突然转身。
