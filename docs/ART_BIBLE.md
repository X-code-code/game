## 视觉世界

原创 2D 叙事绘本插画，采用水彩薄涂、干笔羽毛纹理与细而有起伏的暖棕线稿。鸡有可辨的鸟类结构：层叠的胸羽、翼羽和尾羽，短喙，细而有抓地感的脚爪；表情由眼形、眉线、喙与姿态传达。大轮廓清楚，局部纹理丰富，缩小后仍能读出主体。角色可以有旅人或市井人物的服饰与道具，但服饰属于后续独立层，不嵌入基础身体母版。

参考图以近乎正面的轻微 3/4 角呈现角色。角色母版取**面向画面右侧的轻微 3/4 角**，可见脸部和一侧翅膀，脚完整落地。用户 2026-09-27 提供的[目标游戏视频观察记录](TARGET_VIDEO_GAP_ANALYSIS.md)确定场景组织方向：城市应使用**近俯视、近似平行投影**的大地图，街道、店铺、摊车、绿地和小物在同一平面上连续排布；建筑可见屋顶和立面，但不采用当前冬日街市那种远处地平线、强烈纵深收束的风景画构图。城市、物品和前景统一视角与尺度，角色可比地图建筑略低的观察角度以保留肖像感，但脚点、体积和遮挡必须与地图一致。视频只确定玩法与场景组织，角色仍使用本规范的水彩鸡画风。

线稿为深褐、赭棕而非纯黑，外形线略重，羽毛内部用更细、更稀的断续线与水彩明暗表达。保留轻微手绘抖动，不使用机械均匀粗描边。细节密度接近参考图的胸羽、袖口与布料纹样，但要为游戏缩图删去不可辨的微纹。城市建筑、道具和 UI 必须继承同一线条与纸面水彩语言，不能变成光滑矢量扁平图。

参考色域为奶油白与麦黄色羽毛、赭红和赤陶色点缀、栗棕暗部、灰蓝与鼠尾草绿布料；整体温暖、略褪色，中等偏低饱和度。可参考 `#F3E3C6`、`#D7A45F`、`#A45F42`、`#56697A`、`#8B9A7C` 作为交流锚点，**不是**图像模型必须逐像素匹配的色值。主光从左上柔和照入，暗部保持暖灰棕。水彩叠染可见，但禁止塑料高光、金属 3D 反射、照片质感和生硬赛璐璐阴影。

风格参考的米色纸面可出现在**不透明概念图或母版参考图**中。正式透明角色分层、独立隐藏物和前景资源必须为真实 Alpha，不能把纸面纹理、白底、棋盘格或地面投影烘焙进像素。场景背景可以保留纸张与水彩质感；各层接缝及阴影需在游戏内合成时检查。

## 鸡母版与角色族谱

首个母版是一只**未成年奶油黄小鸡**，单独全身站立，不穿衣、不戴帽、不持物。与参考图下排的幼鸡处于同一视觉世界：头部比成年鸡大、颊羽蓬松、眼睛明亮而非动漫式放大；身体呈饱满的鸟类胸腹形，翼羽分层但不变成人手，两只短脚和脚趾完整可见。用自然羽毛交界区分头、身体、翅膀和腿，便于后续重新绘制 Body、Head、Eyes、Beak、Wing、Legs 等透明层。**不要机械套用旧稿 30–36% 头高限制**；头身比例以风格参考的幼鸡气质、母版审核与 256 px 缩图可读性共同确定。

图中成年公鸡、母鸡与幼鸡的体态差异可为未来角色族谱提供方向，但不能把成年鸡长腿、大鸡冠直接套在幼鸡身上。后续衣装、包、帽、花饰、城市纪念物必须单独设计为可组合层，色彩与织物纹理跟参考图协调，且避开完全照抄其具体角色。母版参考图只定造型，**不是**可直接动画的游戏 SpriteFrame；需要另产分层并在 Cocos 中验证锚点、遮挡与动作。

## 识别性与禁止项

正式隐藏物常以约 128–256 px 显示。轮廓、主色块和关键交互特征优先于微小羽毛线或衣纹；同城目标和背景之间须有足够的边界、层次和点击空间。样张必须同时审核源图与游戏目标缩图。

禁止写实、照片拼贴、3D 渲染、塑料光泽、厚黑漫画线、霓虹高饱和、强透视、文字和水印、额外未要求物体、裁切脚尖翼尖、已有游戏/动画/影视 IP 的明显造型或特定在世艺术家风格复制。禁止以“同参考图一样”代替完整视觉说明；发给 ChatGPT Web 的每个任务包必须自包含并明确列出要上传的参考图。
